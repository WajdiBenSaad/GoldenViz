Citation
--------

If you use GoldenViz in teaching, research, reports, notebooks, or software,
please cite it using the metadata in the repository ``CITATION.cff`` file.

Current citation metadata:

.. code-block:: text

   Wajdi Ben Saad. GoldenViz: Rule-Based Visual Quality Assessment for
   Matplotlib Charts. Version 0.1.0a1.
   https://github.com/WajdiBenSaad/GoldenViz
